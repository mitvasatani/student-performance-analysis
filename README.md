# 📊 Student Performance Data Analysis

## 📌 About the Project

This project analyzes student performance data using Python to
identify patterns and relationships between study habits,
attendance, and academic performance.

The goal is to explore the dataset, calculate useful statistics,
visualize important relationships, and extract meaningful insights
from student performance data.

---

## 🎯 Objectives

- Analyze student academic performance
- Study the relationship between study hours and scores
- Analyze the relationship between attendance and performance
- Compare performance across different subjects
- Identify correlations between different factors
- Create meaningful data visualizations

---

## 🛠️ Technologies Used

- 🐍 Python
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib
- 📈 Seaborn
- 📓 Jupyter Notebook
